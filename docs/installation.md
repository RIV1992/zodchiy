# Установка

«Зодчий» (`zodchiy`) — папка с инструкциями для ассистента. Нужен клиент, который поддерживает навыки в формате `SKILL.md` и чтение связанных файлов.

1. Получить исходники нужной версии репозитория.
2. Перенести **всю папку** `skills/zodchiy` в каталог навыков своего клиента, сохранив её имя и внутреннюю структуру. Расположение каталога определить по документации клиента.
3. Проверить, что клиент обнаружил навык с именем `zodchiy`. Способ включения и явного вызова зависит от клиента.

Внутри установленной папки должны остаться `SKILL.md`, `agents/openai.yaml` и каталоги `references` и `data`. Отдельного `SKILL.md` недостаточно: он ссылается на справочники.

Файлы `docs`, `scripts` и остальные материалы в корне репозитория относятся к сопровождению проекта; переносить их в установленный навык не требуется.

При обновлении заменить папку навыка целиком, сохранив отдельно собственные изменения, если они есть. Проверка пакета описана в [разработке](development.md). Она не подтверждает совместимость с конкретным клиентом или качество результата.
