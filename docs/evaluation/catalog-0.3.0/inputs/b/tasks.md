# Задания

## 1
Используй Зодчего. На основе project-decisions.md предложи композицию каталога по «Первой полосе», а страницы выводов — по «Хору». Дай конкретную структуру и порядок на мобильном экране. Сейчас нужен текст предложения.

## 2
Есть ли в каталоге Зодчего стиль «Лунная эмаль»? Если нет, предложи, как начать визуальную концепцию для ночного городского аудиогида: крупный маршрут, одна ближайшая точка, запуск и пауза аудио. Готовой дизайн-системы для него пока нет. Дай короткое решение, без кода и изображений.

## 3
В index.html исправь только опечатку в кнопке: «Сохрнаить» → «Сохранить».
