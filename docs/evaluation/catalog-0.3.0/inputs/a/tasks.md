# Задания

## 1
Используй Зодчего. Готовим новый редакционный экран «Атласа мастерских» в Material Presence, настроение «Тепло». Учитывай project-decisions.md. Составь компактную спецификацию для разработчика: цветовые роли, типографика, основные поверхности и переходы. В шапке будет большое фото мастерской, ниже длинная статья и таблица расписания. Укажи, что нужно проверить при реализации. Сейчас нужен текст спецификации, не код экрана.

## 2
Подготовь два отдельных текстовых брифа для обработки одной фотографии мастерской: «Присутствие / Style 04» и «Воздушный конструктивизм — двухкрасочная печать». Укажи палитру или способ её получения, форму, фактуру, сохраняемое содержание и входные материалы. Фотографию передадим исполнителю вместе с брифом. Старого эталона у нас сейчас нет. Изображения пока не генерируй.
