# Атлас мастерских: принятые решения

Основной шрифт — Golos Text, длинные тексты — Literata. Текст чтения 18 px / 1.6; интерфейс 16 px / 1.4. Пользователь приходит из каталога, открывает мастерскую, читает материал и возвращается с сохранением фильтра и позиции.

Ошибка заявки и обычный информационный статус имеют разные подписи и значки. Для них используются существующие проектные пары: error #8C2D26 / #FFF1EF, info #255E7D / #EDF6FC. Менять семантику статусов не планируется.
