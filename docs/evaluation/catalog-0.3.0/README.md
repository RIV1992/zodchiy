# Проверка каталога 0.3.0

29 сентября 2026 года. Проверяется выбор и применение справочных материалов в текстовых заданиях и локальной правке. Графическое качество интерфейсов этим прогоном не измеряется.

## Постановка

Первый вариант: ядро 701 слово, три карточки направления, индекс, единый JSON и два редакционных паттерна. Два исполнителя в новых контекстах получили только папку навыка, свои задания и исходные материалы. Ожидаемые ответы и диагнозы им не передавались. Исполнитель A получил два задания, B — три; это отдельные контексты групп, а не отдельный контекст каждого задания.

После чтения результатов редактор сократил формулировку о вариантах и явно описал тёмную адаптацию Material Presence: готовые темы светлые, существующую тёмную основу сохраняют, новые цвета обозначают проектным предложением. Это уточнение по редакционному анализу, а не исправление наблюдавшегося провала первого прохода.

Финальный вариант содержит 690 слов. Два новых исполнителя отдельно выполнили задание о тёмном интерфейсе и одну правку опечатки. Им не были доступны предыдущие ответы в рамках назначенных материалов. Участники использовали свежие контексты; проверяющий знал версии. Независимой слепой оценки человеком не было.

## Что проверил редактор

- Сопоставил задания, проектные ограничения, прочитанные профили и итоговые ответы.
- Проверил обе HTML-правки как ровно одну замену байтов без иных изменений.
- Воспроизвёл все восемь приведённых расчётов контраста в ответе A и четыре отдельных значения из тёмной адаптации.
- Сверил полные роли пяти палитр, шкалу Noto и семантические пары с авторским источником Material Presence v0.2 r1.
- Выполнил пакетный валидатор: ссылки, структура, 690/702 слова, профили и 64 заданные непрозрачные цветовые пары.
- Проверил четыре преднамеренные порчи копии JSON: нечитаемый текстовый цвет, отсутствие `accentInk`, неизвестный алиас действия и неверный HEX. Все четыре отклонены валидатором.
- Сверил контрольные суммы испытанного навыка с финальным пакетом. Карта Codespaces обновлена после изменения валидатора; Markdown и JSON проверены по содержанию и ссылкам.

## Предел вывода

Семь выполнений поддерживают работоспособность маршрутизации каталога в рассмотренных заданиях. Первый проход не выявил материальных ошибок выбранных профилей; последующая редакция уточнила тёмный режим и сократила ядро.

Первые пять заданий не повторялись после точечного уточнения; на финальном варианте выполнены два дополнительных задания. Нет сравнения с базовой версией или без навыка для нового каталога, повторов по разным моделям, пользовательских измерений, готовых экранов и изображений. Модель и параметры не закреплены в переносимом стенде. Общий рост качества UX/UI, точность художественного воспроизведения и экономия времени не доказаны.

Результаты и проверочные задания находятся вне устанавливаемого навыка. Они не добавляют обязательных процедур к обычной работе.
