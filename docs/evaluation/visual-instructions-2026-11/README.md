# Проверка инструкций по изображению

Рабочая версия для исходного сравнения — 0.3.0, коммит `7d09c65d3be8c1ff47affbbc274a34b32bf91b3a`. Для первых двух заданий один исполнитель каждой редакции выполнил оба брифа. Они получили одинаковые исходники. Проверяющая модель видела изображения, брифы и критерии без указания редакции. Каждый ответ оценивался после собственной проверки исполнителя, без исправлений по итогам сравнения.
