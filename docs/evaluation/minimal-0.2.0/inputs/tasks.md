# Задания для интерфейса проката оборудования

Это вымышленный продукт. Данных о реальных пользователях и пользовательских испытаний нет. Рассматривать исходники как предоставленные материалы, а не как увиденный работающий интерфейс.

1. В `navigation/routes.js` приведено устройство каталога и карточек. Пользователь должен выбрать прибор, забронировать его и вернуться к списку. Проведи ревью сценария и предложи необходимые изменения. Код этого задания не меняй.
2. Добавляем раздел «Расходники». Посмотри материалы в `new-screen/` и предложи устройство страницы с поиском, остатками и действием заказа. Требуется краткое проектное решение, без реализации и нового выбора бренда.
3. Компонент кнопки в `shared/current/Button.jsx` заменяет `shared/base/Button.jsx`. Остальные файлы одинаковы в обеих версиях. Проведи ревью изменения и его последствий, предложи необходимые исправления. Код этого задания не меняй.
4. В `small-edit/index.html` исправь опечатку в тексте кнопки «Сохрнаить». Другие изменения не нужны.

Для заданий 1–3 запиши результат в `response.md`: решение или замечание, его основание в материалах и достаточная проверка. Используй относительные пути. В конце укажи, что выполнено в задании 4. Не придумывай выполненные браузерные проверки.
