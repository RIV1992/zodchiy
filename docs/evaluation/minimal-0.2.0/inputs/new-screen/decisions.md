# Действующие решения продукта

Складские позиции имеют стабильный идентификатор, количество и единицу измерения. Название не уникально. Нулевой остаток допустим: заказ создаёт заявку на пополнение и не означает немедленную выдачу.

Общие рабочие страницы используют нейтральный фон, синий акцент основного действия, прямоугольные элементы с радиусом 6 px и плотные строки. Красный обозначает проблему, требующую внимания. Текстовое обозначение статуса сохраняется рядом с цветом.

На странице акции «День мастерской» приняты фиолетовые кнопки с радиусом 24 px и крупные карточки. Это локальное исключение для рекламной страницы; оформление складских экранов оно не меняет.

Термин «Заказать» означает отправить заявку. Обещание мгновенной выдачи не принято. Тексты об остатках получают значение из общей модели склада.
