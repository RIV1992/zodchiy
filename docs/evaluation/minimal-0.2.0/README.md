# Нейтральные задания для уточнений 0.2.0

Материалы вымышлены специально для проверки инструкций и не происходят из личных кейсов. Они не входят в устанавливаемую папку навыка.

## Постановка

Одинаковая копия [входных материалов](inputs/tasks.md) передаётся в два отдельных контекста: с публичной базовой версией `7f8188b194ec7ebcf0874524762cb47bd4a83fcc` и с изменёнными инструкциями. Каждый исполнитель получает только соответствующую папку навыка, рабочие материалы и поручение выполнить четыре задания. Ему не передаются диагнозы, критерии ниже, ожидаемые ответы и результаты другого исполнителя. Назначение сравнительной проверки в поручении не раскрывается.

Форма поручения: использовать «Зодчего» из указанной папки, прочитать нужные справочники и выполнить задания из `tasks.md`; для заданий 1–3 написать `response.md`, для задания 4 исправить HTML. Остальные материалы, инструкции и зависимости не изменять; использовать относительные пути и сообщать только фактически выполненные проверки.

Критерии ниже записаны до получения ответов. Сравнивается содержание результатов и фактический diff маленькой правки. Самобаллы исполнителей не используются.

## Что проверять в результатах

| Задание | Свойства результата |
|---|---|
| Навигация | Установлена проблема обычного входа в каталог; замечена потеря параметров возврата; рассмотрены разные действия над одной сущностью из разных входов при одинаковых правах; чтение исходника не выдано за пройденный браузерный сценарий |
| Новый экран | Продолжена рабочая система; исключение рекламной страницы не распространено; сохранены стабильный id, значение нулевого остатка и смысл заказа; не предложен обязательный новый выбор бренда |
| Общая кнопка | Рассмотрены потребители; обнаружены потери `disabled` и `type`; отсутствие доступного имени в Settings отличено от новой регрессии; выводы о графике не сделаны без стилей/рендера |
| Опечатка | Изменён только текст `Сохрнаить` → `Сохранить`, сохранены структура и атрибуты |

## Границы

Это один сравнительный проход четырёх небольших заданий. Первые три требуют ревью или проектного предложения по предоставленным исходникам, а не реализации и браузерной приёмки продукта. Четвёртое проверяет ограничение фактического изменения, но не изолированную стоимость отдельного вызова навыка: исполнитель уже выполняет пакет заданий.

Исполнители работают в отдельных контекстах одной сессии с наследуемой конфигурацией модели. Модель и параметры запуска не закреплены в переносимом стенде. Исходники позволяют повторить задания, но идентичность ответов не гарантируется. Нет повторов, варианта без навыка, независимых участников и измерений времени/токенов. Результат не устанавливает общий прирост UX/UI или причинный эффект отдельных формулировок.
