# Зодчий

**Навык для UX/UI и художественной концепции с опорой на задачу человека.**

[English](README.md)

Зодчий помогает связать задачу пользователя, устройство интерфейса и визуальное решение, затем проверить результат по требованиям проекта и референсам.

Имя — в пару к [Чтецу](https://github.com/RIV1992/chtets): **Чтец выстраивает мысль, Зодчий — пространство, в котором человек действует.**

## Состояние

**0.2.0 — три уточнения рабочего процесса.** Проверять путь от обычной точки входа до результата и возврата; наследовать решения проекта с явной областью исключений; проверять затронутые экраны при изменении общих компонентов или стилей. Ядро остаётся в пределах 702 слов. Выполненные проверки и границы выводов — в [оценке](docs/evaluation.md).

Инструкции написаны по-русски. Навык состоит из Markdown и YAML, не требует исполняемого кода и не обучает модель.

## Что делает навык

- Помогает найти причину проблемы: модель продукта, сценарий, иерархия, композиция или реализация.
- Поддерживает поиск вариантов для открытого вопроса и реализацию уже выбранного направления.
- Связывает референс, наблюдаемое свойство, приём реализации и фактическое изображение.
- Разделяет проверку смысла и поведения, визуального решения и реализации.
- Помогает записать урок вместе с его основаниями и границами применения.

## Установка и использование

Перенесите всю папку [`skills/zodchiy`](skills/zodchiy) в каталог навыков, поддерживаемый вашим клиентом. Сохраните `references/` рядом с `SKILL.md`. Подробности — в [инструкции](docs/installation.md).

Если клиент поддерживает явный вызов навыка:

```text
Используй $zodchiy: проверь UX/UI этого интерфейса по задаче пользователя,
требованиям проекта и приложенным референсам.
```

Приложите само задание и нужные материалы. Успешная сборка не подтверждает визуальную приёмку человеком.

## Устройство репозитория

| Путь | Содержание |
|---|---|
| [skills/zodchiy/SKILL.md](skills/zodchiy/SKILL.md) | Короткое ядро и выбор справочника |
| [skills/zodchiy/references](skills/zodchiy/references) | Рабочие поверхности, объяснение, чтение, визуальное направление и опыт |
| [skills/zodchiy/agents/openai.yaml](skills/zodchiy/agents/openai.yaml) | Метаданные отображения для совместимых клиентов |
| [docs/installation.md](docs/installation.md) | Установка и переносимое использование |
| [docs/development.md](docs/development.md) | Границы пакета и правила сопровождения |
| [docs/evaluation.md](docs/evaluation.md) | Что подтверждает эта версия |
| [scripts/validate.py](scripts/validate.py) | Проверка структуры, ссылок и размера ядра |

Предел ядра — 702 слова по разделению пробелами, включая frontmatter. Справочники читаются по необходимости. Личные кейсы и частные материалы, в том числе их замаскированные копии, в публичный пакет не входят.

## Проверка пакета

```bash
python3 scripts/validate.py
```

Это проверка упаковки, а не качества дизайна. См. [правила участия](CONTRIBUTING.md) и [историю изменений](CHANGELOG.md).
